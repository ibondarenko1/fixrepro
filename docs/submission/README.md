# FixRepro submission package

This directory contains the public, copy-ready material for the VoltHacks 2026 entry. It includes final Devpost text, screenshots captured from the real localhost application, a 2:10 recording plan, matching captions, judge answers, and the manual submission checklist.

The video has not been recorded, uploaded, or represented by a placeholder file. Devpost entry remains manual.

## Files

- `DEVPOST_FINAL.md` - paste-ready project text
- `SCREENSHOTS.md` - image order, captions, and alt text
- `VIDEO_SCRIPT.md` - spoken script
- `VIDEO_SHOT_LIST.md` - timed browser actions
- `CAPTIONS.srt` - upload-ready captions
- `JUDGE_QA.md` - short answers for common judge questions
- `SUBMISSION_CHECKLIST.md` - final manual checks
- `screenshots/` - four generated PNG images

All material describes a synthetic localhost demonstration. No private research process records belong in this package.
