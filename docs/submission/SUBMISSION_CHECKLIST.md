# VoltHacks submission checklist

## Repository checks

- [ ] Confirm the CI badge is green.
- [ ] Confirm the GitHub repository is public.
- [ ] Open the repository link in a logged-out browser session.
- [ ] Confirm the tracked demo bundle verifies with its published digest.
- [ ] Confirm the README quick start works from a clean clone.
- [ ] Confirm no secret, private key, runtime evidence, or video binary is tracked.

## Screenshot checks

- [ ] Open all four PNG files at full size.
- [ ] Confirm no loading state, error, personal data, local path, or notification is visible.
- [ ] Upload the four screenshots in the recommended order.
- [ ] Use `01-dashboard-overview.png` as the cover image.
- [ ] Add the captions and accessible alt text from `SCREENSHOTS.md`.

## Video checks

- [ ] Review the completed final video from beginning to end.
- [ ] Confirm the real Roomba image is described only as a supplemental physical-output witness.
- [ ] Confirm the video says the Roomba received no firmware and was not the OTA target.
- [ ] Confirm no complete automated two-signal Roomba run is claimed.
- [ ] Keep bookmarks, email, Devpost account data, usernames, notifications, unrelated terminals, and private material off screen.
- [ ] Upload the video in an accessible unlisted form that Devpost can play.
- [ ] Test the video while logged out.

## Devpost text checks

- [ ] Paste the final project text from `DEVPOST_FINAL.md`.
- [ ] Add only the implemented technologies listed in `devpost/overview.json`.
- [ ] Add `https://github.com/ibondarenko1/fixrepro` as the repository URL.
- [ ] Confirm the text calls the lab synthetic and the evidence tamper-evident.
- [ ] Confirm `PATCH_VERIFIED` is limited to the defined regression under tested conditions.
- [ ] Confirm the Roomba proof of concept is described as supplemental to the reproducible Docker workflow.

## Devpost upload checks

- [ ] Upload the four screenshots in order: overview, full dashboard, report, mobile dashboard.
- [ ] Add the unlisted video URL only after the recording is uploaded and tested.
- [ ] Preview the complete submission on desktop and mobile.
- [ ] Confirm no private information is visible in any media or text.
- [ ] Confirm every link opens from the preview.

## Final submission checks

- [ ] Submit before 11:00 PDT on September 5, 2026.
- [ ] Treat 14:00 PDT only as the hard platform deadline.
- [ ] Confirm the entry is submitted, not left as a draft.
- [ ] Save proof of submission and the final public entry URL.
